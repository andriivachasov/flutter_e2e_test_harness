# ADR-007 (D7): Default device matrix

**Status:** accepted · 2026-08-26

## Decision

**1 recent iOS simulator + 1 recent Android emulator** (configurable)

## Rationale

Latest stable iOS + recent API level (34/35). Older-OS coverage is config, not v1 scope.

See `refined_requirements.md` (D7) and the playbook steps that apply it.
